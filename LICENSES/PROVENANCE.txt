PTHotKey: original authors' permission
The original distribution is linked by Rogue Amoeba's own source-code page:
https://rogueamoeba.com/opensource/
Archive: https://rogueamoeba.com/sources/HotKeysLib3.zip
Archive SHA-256:
176a8482cee763c96c0cd0cc9a29d28bdaff661f436adb1bc3b366413233dd82

HotKeysLib3/LICENSE.txt names Rogue Amoeba Software LLC, Quentin D. Carnicelli,
Finlay Dobbie, and Vincent Pottier and expressly permits use, modification,
publication, distribution, sublicensing, and sale. HotKeysLib3.txt preserves
that grant, with only CR line endings normalized to LF. Unlike standard MIT,
the original text has no notice-retention clause; do not replace it with a
different license template. We retain the complete grant and source credits.

Source linkage, not a license borrowed from a related fork
The original archive's PTHotKeysLib/src directory contains these same eight
files: PTHotKey.h/.m, PTHotKeyCenter.h/.m, PTKeyCodeTranslator.h/.m, and
PTKeyCombo.h/.m. Direct source comparison shows the shared implementation and
file-level Carnicelli/Cliché/Dobbie credits. The pinned copies are derivatives,
not byte-identical copies of this older release. In particular, the translator
contains the same class and Unicode translation operation, with the later TIS
keyboard-layout API and memory-management changes. The author-hosted patch
also documents that API transition:
https://rogueamoeba.com/sources/HotKeys3-105SDK.patch

The dependency's own 64-bit port commit records the subsequent source changes:
https://github.com/joaomoreno/ShortcutRecorder/commit/a1448a1ba1590dce8aac4c14b1c247700d07ea07
ShortcutRecorder-provenance.json records SHA-256 hashes of the original archive
files, the pinned files, the license, and the author-hosted patch, along with
the pinned Git blobs. It allows this comparison to be repeated precisely.
